# Portfolio Images

Organized image folders for the Logan Burns portfolio site.

## Folders

| Folder | Use |
|--------|-----|
| `hero/` | Hero section — main top-of-page photo |
| `about/` | About section profile photo |
| `case-studies/` | Case study and project images |
| `general/` | Any other site images |

## Current files

- `hero/logan-burns-hero.png` — Hero photo (right side of homepage)

## Adding images

1. Save your image to the matching folder
2. Use lowercase names with hyphens (e.g. `forbidden-bourbon.jpg`)
3. Update the `src` path in `index.html` if needed
4. Commit and push — GitHub Pages redeploys automatically
